# Dungeon Pact · Closed Alpha

Dungeon Pact is a puzzle deckbuilder and dungeon crawler: plan your moves,
build your deck and lead your guild deeper into the dungeon.

This repository only hosts the **closed alpha builds** for invited testers.
If you found it by chance: thanks for the curiosity, but the builds are
reserved for the alpha group (see [LICENSE](LICENSE.md)).

## Download

**[Download the latest version for Windows](https://github.com/esentar/dp-alpha-builds/releases/latest/download/DungeonPact_Alpha_Setup.exe)**

Older versions and release notes are in the [Releases](../../releases) page.

**Requirements:** Windows 10 or 11, 64-bit.

## Install

1. Run `DungeonPact_Alpha_Setup.exe`.
2. If Windows shows **"Windows protected your PC"**, click **More info**,
   then **Run anyway**. It appears because the game does not have a
   digital signature yet.
3. Follow the installer. No administrator rights are needed.

The installer creates two shortcuts: **Dungeon Pact** (system language)
and **Dungeon Pact (English)**.

## Updating

Download the new version and install it over the old one.
Your saves are stored separately and are kept between versions.
In rare cases an update may require restarting a run in progress:
we will always announce it on Discord first.

## Feedback

Bugs, ideas and complaints are all welcome on Discord:
**[Join the testers' Discord](https://discord.gg/sufMzuwGeU)**

When reporting a bug, please include the version number shown in the game.

## Good to know

- This is a work-in-progress build: expect bugs, placeholder text and
  unfinished parts. Finding them is the whole point.
- The alpha sends **anonymous gameplay data** (runs, floors reached,
  cards played) to help balance the game. No personal data is collected.
- Please do not share the builds or the download link outside the alpha group.
